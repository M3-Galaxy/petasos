# Petasos v2 (ペタソス)

> **身体性を伴うカードデッキと、静かな思考の星空。**  
> 紙とデジタルの美しい棲み分けを目指す、個人用超軽量ローカルファースト・思考キャプチャ＆発掘ツール。

---

## 🌌 コンセプト

Petasos（ペタソス）は、ギリシャ神話で旅や商業の神ヘルメスが被る「つば広の旅帽」に由来するメモアプリです。  
情報が無限に溢れる現代において、無段階スクロールや肥大化したドキュメント構造をあえて排し、**「紙の単語帳を親指で1枚ずつめくる身体性」** と **「夜空の星々を結びつけるような有機的なリンク」** を追求しています。

---

## 🌟 主な特徴

### 1. 十字フィジカル・カードデッキ
* **時間の地層をめくる（上下スワイプ / ホイール / キーボード ↑↓）**:
  * 画面上には現在のカードと前後カードのみをスライディングウィンドウとして配置。
  * スワイプ指に吸い付く物理的追従と、閾値を超えた瞬間の心地よいめくりアニメーション。
  * 日時バッジにより「今日」「昨日」「◯日前」など時間の地層を直感的に把握。
* **関連リンクを発掘する（左右スワイプ / ←→）**:
  * 結ばれている思考（相互リンク）が存在する場合、左右にカードの端がのぞき、横スワイプでリンク先へ水平移動。
* **ロケットワープ機能**:
  * 右下のロケットボタンから「最古の地層へジャンプ」「最新の思考へ帰還」「ランダム発掘」が可能。

### 2. 3層の閲覧・執筆構造
* **① デッキ（一覧・めくり）**:
  * 思考の断片をめくり、偶然の出会いや過去の記憶を発掘する場。
* **② 閲覧モード（安全地帯・全文読書）**:
  * カードをタップすると全画面モーダルで安全に全文読書。
  * チェックボックス（`- [ ]` / `- [x]`）を直接タップしてタスク消化。
  * 箇条書き（`- ` / `* `）や見出しのMarkdownパース表示。
  * テキストのドラッグ選択・ワンタップクリップボードコピーに対応。
* **③ 編集モード（ノイズレス・明示的コミット）**:
  * 閲覧モードからペンアイコンをタップして執筆へ遷移。
  * カテゴリ入力欄にフォーカスすると既存カテゴリのサジェストチップがふわっと出現。
  * 保存ボタン（コミット）を押すことで明示的に思考を記録。

### 3. 思考の整理・複数選択モード
* **複数カードの一括整理**:
  * ヘッダーの選択ボタンまたはカード長押しで「整理モード」へ突入。
  * **相互リンク**: 選択したメモ同士を星座のように相互に結びつける。
  * **グループ化**: 選択したメモのカテゴリを一括変更。
  * **結合**: メモ内容を統合し1つの新規メモに集約。
  * **Markdownコピー**: 選択したメモを一括でMarkdownドキュメントとしてコピー。
  * **手放す（アーカイブ）**: デッキから静かに退避。
* **カード一覧グリッド**:
  * 下部ツールバーの「一覧」ボタンから、全メモをグリッドタイルで俯瞰して選択可能。

### 4. ローカルファースト & GitHub 双方向同期
* **IndexedDB ブラウザローカル完結**:
  * 外部サーバーを介さず、すべての思考はユーザーの端末内（IndexedDB）に安全に保存。
  * JSONエクスポート、データ全初期化（リセット）機能を標準搭載。
* **GitHub REST API による静かな同期**:
  * ユーザー所有のPrivateリポジトリと直接通信（1メモ＝1JSONファイル）。
  * オフライン中の操作は「同期待ちキュー」に蓄積され、通信復帰時に自動プッシュ。
  * Last-Write-Wins (LWW) による安全な差分マージ。

### 5. 5大静謐外観テーマ & 星屑テクスチャ
* **トワイライト（ドーン）**: 夜明けブルーグレー × 静謐グレー × ティール
* **トワイライト（ダスク）**: 夕暮れラベンダーグレー × 羊皮紙 × コーラル
* **エイリアン・ライム**: 漆黒の深宇宙 × ブラックカード × 蛍光ネオンライム
* **スターダスト**: 星間空間のディープネイビー × 澄んだスターライト
* **セージ・オリーブチョーク**: 静かな知性を感じさせるセージグリーン × チョークホワイト
* 背景の微細な星屑粒子エフェクト（トグル切替可能）

### 6. PWA（Progressive Web App）フル対応
* スマートフォンのホーム画面に追加することで、ネイティブアプリ同様のフルスクリーン動作。
* Service Worker による完全オフライン動作。
* ノッチやセーフエリア（`env(safe-area-inset-*)`）に最適化されたモダンUI。

## 🚀 使い方・キーボードショートカット

| 操作 | デスクトップ | スマートフォン (タッチ) |
| :--- | :--- | :--- |
| **前のカード / 次のカード** | `↑` / `↓` または マウスホイール | 上下スワイプ |
| **関連リンクへ移動** | `←` / `→` | 左右スワイプ |
| **メモ詳細を開く** | `Space` / `Enter` または クリック | カードタップ |
| **新規メモ作成** | ヘッダーの `＋` ボタン | ヘッダーの `＋` ボタン |
| **複数選択（整理モード）** | `チェックボックス` または ヘッダーボタン | カード長押し / チェックタップ |
| **モーダルを閉じる** | `Esc` キー または `×` ボタン | `×` ボタン または 背景タップ |

## 🛠️ 技術スタック

* **コア**: Pure HTML5 / Vanilla CSS3 / Modern JavaScript (ES Modules)
* **ストレージ**: IndexedDB (APIラッパー自作、ゼロ外部依存)
* **同期エンジン**: GitHub REST API (Octokit等の肥大ライブラリ不使用、Fetch API直接通信)
* **オフライン**: Service Worker (Cache Storage)
* **ビルドツール**: なし（ビルド不要・静的ファイルサーバーのみで即時動作）

## 💻 ローカル開発・起動方法

Node.js環境があれば、静的ファイルサーバーで即座に起動できます。

```bash
# 静的ファイルサーバーで起動（例: serve）
npx serve -p 3000
```

ブラウザで `http://localhost:3000/` を開きます。
