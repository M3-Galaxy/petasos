# Petasos v2

> 身体性を伴うカードデッキと、静かな思考の星空。  
> 紙とデジタルの美しい棲み分けを目指す、個人用超軽量キャプチャ＆発掘ツール。

---

## 🌟 主な特徴

- **十字フィジカル・カードデッキ**:
  - 無段階スクロールを排し、紙の単語帳を親指でめくるような1枚ごとの重みと吸い付きを再現。
  - 上下めくりで時間の地層を行き来し、横スワイプで関連リンク（結ばれている星）を発掘。
- **3層の閲覧・執筆構造**:
  - `デッキ（一覧） ➔ 閲覧モード（安全地帯・全文スクロール・タスク消化） ➔ 編集モード（ノイズレス・明示的コミット）`
- **IndexedDB ローカル永続化**:
  - 外部DBに依存しないブラウザ完結の超軽量設計。
- **静かな同期待ちキュー**:
  - タスクチェックや編集内容を自動でキューイング。
  - Lucide アイコン（未同期時はシアン発光の `CircleDashedCheck`、同期完了時は静かな墨色の `CircleCheck`）で状態を可視化。
- **二重外観テーマ**:
  - **トワイライト（薄暮の星屑）**: ラベンダーグレー（`#92909e`）背景 × 羊皮紙カード（`#dedbd7`）。
  - **デイライト（澄んだ光）**: クリアホワイト × シアンアクセント。
- **環境設定モーダル**:
  - テーマ切替、ローカルデータのJSONエクスポート、キュークリア、将来のGitHub同期設定欄。

---

## 🚀 起動方法

```bash
# 静的ファイルサーバーで起動
npx serve -p 3000
```
ブラウザで `http://localhost:3000/` を開きます。
